# Inicio rápido — cómo usar este harness

1. Descomprime `stratum-harness.zip`.
2. `git init && git add . && git commit -m "chore: initial harness"`
3. Abre la carpeta con Claude Code (`claude`) u otro agente: leerá CLAUDE.md → AGENTS.md → memory.md.
4. Primer prompt sugerido:
   > "Lee AGENTS.md, memory.md y process/tasks.md. Empecemos el Sprint 0 por S0-01 y S0-02.
   >  Antes de implementar, muéstrame el plan y pregúntame lo que no esté claro."
5. Al cerrar cada sesión pide: "Actualiza memory.md y process/tasks.md".
6. Puedes borrar este archivo cuando ya no lo necesites.
