# Alcance y paridad — Stratum

## Dentro de alcance (paridad con Compositor + diferenciales)
### Capas
- [ ] Capas y carpetas con blend modes (27, agrupados como Photoshop) y opacidad
- [ ] Máscaras de capa: pintar, rellenar, invertir, desenfocar, difuminar; vincular/desvincular
- [ ] Clipping masks y máscaras de carpeta
- [ ] Adjustment layers: Tono/Saturación, Niveles, Curvas, Exposición, Mapa de degradado, Grano
- [ ] Combinar abajo, combinar capas, combinar grupo; duplicar, renombrar inline, reordenar/anidar con drag & drop
- [ ] Arrastrar capas entre documentos abiertos
### Transformar
- [ ] Mover, escalar, rotar, voltear no destructivos; distorsión libre
- [ ] Transformar varias capas o carpeta a la vez; snapping a bordes/centros con guías
- [ ] Valores exactos (posición, tamaño, escala, ángulo) con flechas
### Selecciones
- [ ] Marquee rectangular/elíptico, lazo libre y poligonal, varita mágica
- [ ] Sumar/restar, mover contorno, mover/duplicar píxeles
- [ ] Cargar píxeles o máscara como selección
- [ ] Relleno según contenido (IA) incluido extender lienzo
- [ ] ⭐ Selección inteligente por clic (IA) — diferencial
### Pintura y retoque
- [ ] Pincel (tamaño, dureza, opacidad, flujo, presión), línea recta con Shift
- [ ] Pincel corrector puntual, tampón de clonar (alineado, muestrear capa/todas), herramienta desenfocar
- [ ] Degradado, formas (rect, rect redondeado, elipse), cuentagotas, selector de color completo
### Ajustes y filtros
- [ ] Niveles (Auto), Curvas, Tono/Sat, Exposición, Mapa de degradado, Grano, Invertir
- [ ] Desenfoque gaussiano y de movimiento (que se extienden fuera del borde de la capa)
- [ ] Añadir ruido, Corrección de lente, Quitar fondo (IA)
- [ ] Preview en vivo limitado a la selección si existe
### Lienzo y archivos
- [ ] Varios documentos en pestañas; recorte con snapping (Alt simétrico)
- [ ] Tamaño de lienzo e imagen; downsampling de calidad al alejar; rejilla de píxeles al acercar
- [ ] Importar JPEG, PNG, WebP, HEIC, TIFF, PSD (básico); pegar y soltar desde otras apps
- [ ] Exportar JPEG/PNG/WebP/AVIF con preview y tamaño estimado; copiar combinado
- [ ] Formato propio .stratum; autoguardado; recuperación tras cierre inesperado
### Diferenciales web
- [ ] PWA instalable, offline; Command Palette; HUD; barra contextual; i18n es/en; tema claro/oscuro
